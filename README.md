## Abagnale – Voice-Based Design Ideation
Abagnale is a human-centred AI research project (5 weeks), built as a design probe: a voice AI that acts as a design team for solo designers.

While testing it, I discovered a problem I call _"underprompting"_: when people talk to a voice AI, they give it far less context than when they type. I solved this by letting the AI learn context over time, so the conversation gets smarter the more you use it.
